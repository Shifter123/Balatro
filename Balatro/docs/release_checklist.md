# 发布检查清单

## Steam 发布前检查

### 1. 技术准备
- [ ] 游戏在所有目标平台编译成功
- [ ] 游戏在 Windows 10/11 测试通过
- [ ] 游戏在 macOS 测试通过
- [ ] 游戏在 Linux 测试通过
- [ ] 内存泄漏测试通过（运行4小时以上）
- [ ] 帧率稳定性测试（目标60FPS，最低30FPS）
- [ ] 存档系统正常工作
- [ ] Steam Cloud 同步正常

### 2. Steamworks 配置
- [ ] Steam App ID 已分配
- [ ] Steamworks 后台配置完成
- [ ] 成就系统配置完成（16个成就）
- [ ] 排行榜配置完成（3个排行榜）
- [ ] 云存档配置完成
- [ ] 商店页面配置完成
- [ ] 上传截图和宣传图
- [ ] 上传预告片

### 3. 商店页面
- [ ] 游戏描述已填写
- [ ] 标签已设置
- [ ] 分类已设置
- [ ] 定价已设置
- [ ] 发布日期已设置
- [ ] 年龄分级已提交
- [ ] 截图已上传（至少5张）
- [ ] 预告片已上传
- [ ] 胶囊图已上传

### 4. 法律与合规
- [ ] 隐私政策已准备
- [ ] EULA 已准备
- [ ] 第三方许可已确认
- [ ] 年龄分级申请已提交
- [ ] 内容审核已通过

### 5. 营销准备
- [ ] 社交媒体账号已创建
- [ ] 新闻稿已准备
- [ ] 社区公告已准备
- [ ] Discord 服务器已设置（可选）

### 6. 发布当天
- [ ] 最终构建已上传
- [ ] 商店页面已发布
- [ ] 社交媒体公告已发布
- [ ] 社区公告已发布
- [ ] 监控错误报告

### 7. 发布后
- [ ] 监控玩家反馈
- [ ] 监控崩溃报告
- [ ] 准备热修复（如需要）
- [ ] 收集数据分析

## 构建版本号规范

- 主版本号：重大功能更新或破坏性变更
- 次版本号：新功能发布
- 修订号：问题修复和细节优化

示例：`1.0.0` -> `1.1.0` (新功能) -> `1.1.1` (修复)

## 紧急回滚流程

1. 在 Steamworks 后台切换到上一个稳定版本
2. 通知玩家正在调查问题
3. 分析崩溃报告
4. 修复问题并测试
5. 上传新版本
6. 更新公告
